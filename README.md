
# 🚀 ExamPro – Online Examination System

ExamPro is a browser-based online examination platform that allows students to take multiple-choice tests, manage their time, and evaluate their performance instantly.

🌐 **Live Demo:** https://sehgal1001.github.io/ExamPro/

## ✨ Features

- 📚 **Multiple Subjects:** Mathematics, Physics, Chemistry, Biology, Computer Science, Web Development, HTML & CSS, JavaScript, and General Knowledge.
- ⏱️ **Timed Examination:** 10-minute examination duration.
- 📝 **MCQ-Based Tests:** Multiple-choice questions with four options.
- 🔖 **Mark for Review:** Mark questions to revisit later.
- 🔄 **Question Navigation:** Navigate between questions using the question palette.
- 📊 **Live Progress Tracking:** Monitor answered and unanswered questions.
- ⚡ **Instant Results:** Get your score, percentage, grade, and performance summary.
- ✅ **Answer Review:** Check correct answers with explanations.
- 🌙 **Dark & Light Mode:** Switch between different themes.
- 💾 **Local Storage:** Save the latest exam result and theme preference in the browser.
- 📱 **Responsive Design:** User-friendly examination interface.

## 🛠️ Tech Stack

## 🚀 Getting Started

Follow these steps to run ExamPro locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Sehgal1001/ExamPro.git
```

### 2. Navigate to the Project Folder

```bash
cd ExamPro
```

### 3. Run the Project

Open `index.html` in your preferred web browser.

No additional installation or build tools are required.

## 📖 How to Use

1. Open the ExamPro application.
2. Select your preferred subject.
3. Enter your name.
4. Click on **Start Examination**.
5. Answer the multiple-choice questions.
6. Use the question palette to navigate between questions.
7. Mark questions for review if needed.
8. Submit your examination.
9. View your performance and score.
10. Review correct answers and explanations.

## 📊 Examination Details

| Parameter | Details |
|---|---|
| Questions | 10 |
| Duration | 10 Minutes |
| Question Type | Multiple Choice |
| Marks per Question | 1 |
| Negative Marking | No |
| Result | Instant Evaluation |

## 🎯 Scoring System

- Correct Answer: +1 Mark
- Incorrect Answer: 0 Marks
- Unanswered Question: 0 Marks

Your final percentage and grade are calculated automatically after submission.

## 🔒 Data & Privacy

ExamPro operates directly in the browser without requiring an account or backend server.

- Theme preference is stored using LocalStorage.
- The latest examination result is stored locally.
- No account registration is required.
